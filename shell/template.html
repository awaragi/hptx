Presentation tip

Full screen recommended

This deck is laid out for full screen. Enter full screen for the best typography, spacing, and slide flow.

You can also use F11 (Windows) or ⌃⌘F (Mac) in most browsers.

Settings

Load or paste a theme and apply it in this browser (overrides defaults and any bake). To create a theme, use Generate theme, then come back here and apply it. To bake a theme into the built file, set theme in deck.json and build — bake appends over shell defaults (see Instructions).

Load a .css file (picker or drag onto the box), or paste from your AI assistant. The theme stays in this browser for presentations. If the theme hides the gear, C still opens Settings. To ship the theme in the file, put the same :root values into the main stylesheet.

Paste into chat; the assistant asks for brand colors (which is the primary CTA), accent roles, and single vs dual theme, then returns a complete :root CSS block remapped from the live baseline in this file.

Uncheck a slide (or a whole group) to hide it from navigation, the agenda, and the slide count. Uncheck Agenda to show only the title block on the home page. Saved in this browser only, the same way as an applied theme.

When on, Left/Right, Up/Down, and Page Up/Down step inside the current slide, then change slides at the ends. Saved in this browser only. Other shortcuts stay available.

When on, returning to a slide restores the step you left on (session only; cleared on refresh). When off, each visit uses the slide’s authored landing step. Preference is saved in this browser; applies in clicker and normal mode.

Removes the applied theme, hidden-slide selection, clicker-mode and remember-step preferences, and light/dark preference from this browser. Does not change the HTML file.
